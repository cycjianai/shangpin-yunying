# 业务状态机与批量任务

## 三段职责

1. **策略执行**：根据商品快照、成本、销量、毛利底线、锁价/静默配置计算 `target_price`，并解释命中、跳过和保护原因。
2. **平台推送**：把目标价转换为修改原价、下线活动、修改活动价、新建活动或追加活动等平台动作。
3. **平台验真**：通过独立读取路径确认目标 SKU 的有效终端价。验真结果才能驱动本地 `success`。

三段不能互相冒充。策略成功不是平台成功，写接口被接受也不是最终价格生效。

## 候选冻结与过滤

为每次 job 固定 `task_id`、平台、门店、策略版本、候选快照版本和目标价。开始后不得因后台数据刷新悄悄扩大候选集。

候选阶段排除并记录原因：

- `target_price` 为空；
- 策略结果为锁价、跳过或需人工复核；
- 已验真成功，或处在显式配置的失败冷却期；
- 路由为 `noop`；
- 超出价差、毛利或其他业务保护；
- 缺少平台要求的真实商品/SKU 标识；
- 多规格 SKU 无法唯一定位；
- 当前活动冲突或平台状态不足以做安全决定。

恢复任务时重新预检会话和平台状态，但继续使用冻结的任务范围；若目标价已过期，应终止并创建新任务，不能静默换价。

## 统一价格动作

先从平台读取：当前原价、当前生效活动、SKU 级活动价、活动状态和可确认的终端价。只对唯一且符合本任务管理范围的活动执行变更。

| 目标关系 | 期望结果 | 平台动作 |
| --- | --- | --- |
| `target > original` | 终端价提高为目标价 | 先下线会压低终端价的可管理活动，再把目标 SKU 原价改为目标价 |
| `target == original` | 回到无活动原价 | 下线该 SKU 的可管理折扣参与行；无活动时为 `noop` |
| `target < original` | 保持原价，以活动承接降价 | 修改唯一可管理活动价；否则在批次共享活动中创建/追加 SKU |

使用平台最小货币单位或 `Decimal` 比较。若多个活动共同影响终端价、活动归属不明或平台展示价与已知字段不一致，停止该 SKU 并人工复核。

“当前活动价已经等于目标价”只在活动已生效、SKU 匹配唯一且终端价读回一致时才是 `noop/success`。

## 幂等与不确定结果

推荐幂等键至少包含：`platform + store + task_id + sku_id + intended_action + target_price`。持久化请求尝试、平台活动 ID、写前状态、写响应摘要和验真状态。

- 明确未发送：可安全重试。
- 业务校验、权限或认证失败：不重试；修复根因后从预检恢复。
- 限流或瞬时服务错误：有界指数退避并加入抖动，尊重平台提示。
- 发送后超时/断线：状态为 `unknown`，先读回；只有证明未生效且动作幂等时才重试。
- 创建共享活动超时：先按批次标记、名称、时间窗和平台 ID 查重，避免重复创建活动。

## 异步 job 状态

最低状态集合：`queued`、`preflighting`、`running`、`stopping`、`stopped`、`completed`、`failed`。SKU 结果至少区分 `pending`、`success`、`failed`、`skipped`、`unknown`。

进度至少包含：`total`、`completed`、`success`、`failed`、`skipped`、`unknown`、`current_sku`、`first_failure`、`updated_at`。状态和 SKU 结果应持久化，不能只放进程内存。

停止是协作式的：停止发起新写操作，让在途请求完成回读，把尚未开始的 SKU 保留为可续跑，而不是伪装成成功。恢复时只处理未验真成功的 SKU，并在写前重新读当前状态。

## 并发与共享活动

写并发和验真并发分开配置。固定 worker 池限制在途请求；共享活动的创建、追加、修改必须按活动或门店加锁。共享浏览器页和动态 token 若非并发安全，也必须排队。

并发从 1 开始，用阶梯结果选择。历史上某环境的“写 8、验 6、1000 条通过”只能证明当时组合可行，不能作为新环境默认值。

## 补偿与回滚

写前保存原价、活动价、活动 ID、参与状态和读回来源。补偿必须执行原动作的业务逆操作，并再次验真：

- 恢复原价可能需要先下线本批创建的活动，再修改原价；
- 不能简单调用一次 `push_target_price(old_original_price)`，因为路由可能把旧原价解释成新的折扣目标；
- 共享活动不能因一个 SKU 回滚而误伤其他 SKU；只操作目标参与行；
- 当前平台状态已被其他人或任务改变时，不自动覆盖，进入冲突状态。
