# 搬品冲突回退复核任务入口

只在用户要求复核搬品时为避开“名称完全相同 / 条码完全相同”而改过字段的商品时加载。这个任务不是失败重试，
不新增、编辑、删除或覆盖牵牛花商品；平台侧只读，唯一写入是用户指定的本地映射工作簿。

## 最小执行流

1. 冻结当前牵牛花租户和用户指定工作簿、工作表、结果列与目标 SKU 列。
2. 只把结果列明确标记为`商品名称变化`、`条形码变化`、`商品名称变化+条形码变化`的行加入 manifest；
   `成功`及其他行不进入任务。
3. 用目标 SKU 读取当前迁入商品；按被标记的字段各自只删除末尾一个数字 `1`，名称得到查询前缀，条码得到精确查询值。
4. 在当前主档只读查询原候选，排除本次迁移 manifest 中的全部目标 SPU/SKU，再核对商品语义、品牌与规格。
5. 按固定 J/K Schema 回填并独立重开工作簿验证；任何平台商品写入均为越权。

完整字段、异常和完成门只读[搬品冲突回退复核合同](../copy-conflict-reconciliation-contract-v1.md)。
