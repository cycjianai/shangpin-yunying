# 任务分支：插件属性填充

本模式必须实际运行和验收用户点名的插件链路。不得用 CDP 直连 writer 的成功冒充插件任务成功，也不得为优化插件
属性功能修改无关稳定能力。

冻结插件版本、当前平台、门店、目标集合和任务 ID；按 `1→10→100` **商品数放量阶梯（不是并发）**验证页面准备、
插件任务终态、平台保存、独立字段回读、内存峰值、交付率和填充率。writer 并发仍固定服从共享 `1→2→4` 资源门；
任一级未达 100% 时停止扩量并修复根因。

结果仍映射到统一渠道属性字段 ID 和七表。`来源策略=plugin_native_result`；插件显示完成但平台未回读时使用
`pending_verify`，不能写 `verified_complete`。
