# 牵牛花主图品牌水印扫描（只读）

用于已授权商品集合的水印盘点、试扫确认和 SPU 清单导出。接口取图为 `runtime_guided`：端点、字段和签名必须来自当前页面成功证据。识别支持配置不同品牌，不代表能自动识别任意未知水印。

## 品牌与判定范围

- 已知品牌文字：可用 OCR 搜索品牌名及用户认可的别名，OCR 命中先作为候选。包装上正常的商标、店铺角标、重复浅色水印语义不同；只有用户把某类标识也列入处理范围时才纳入。
- 已知图案：使用用户提供或已确认的参考图，裁出文字水印、边框、Logo/吉祥物分别建立模板。浅色文字可用灰度高通、多尺度相关匹配；彩色角标可用原灰度匹配。匹配得分不是概率。
- 未知品牌：OCR 与视觉可以发现疑似覆盖文字/角标，但不能仅凭文字存在判为水印，也不能声称任意品牌零漏检。先交候选和原图供确认，再加入品牌规则。
- 用户只确认一种样式，不自动授权扩大到所有边框、包装或其他品牌；当前授权也不等于授权付费生图、去水印或改商品。

## 登录态与分页取图

1. 复用当前登录页面，冻结可见租户名称与 ID、筛选条件、列表顺序、主图槽位和当前总数。列表首图与轮播图、详情图、门店渠道图的范围分开。
2. 捕获一次当前原生成功列表请求。只读分页优先在同一列表页调用接口，不逐个打开商品、不导出 Cookie、不复制签名。
3. 遵守平台受保护请求合同：每页请求从当前 H5guard 获得绑定 URL/method/body 的新签名；协议版本来自现场证据。A9 可能带后缀，比较已验证的版本部分而非把整个字段当版本。403/身份冲突停止并排查，不能轮换版本盲试。
4. 按现场返回结构提取 SPU 字符串、商品名、主图 URL；列表成员是 SPU 时不要把其 SKU 数量当分页条数。未知字段或非字符串精确 ID 先停下确认，不能通过 Number 再转回字符串。
5. 保存每页成功码、页码、条数和总数；最终验证连续页码、总数一致、唯一 SPU 数等于授权集合。数据变化导致重复/缺项时重查差异，不能仅将重复去掉便宣称全量。
6. 原图按 URL 去重下载并保留各 SPU 映射。仅移除已证实为缩略图变换的 URL 后缀，不盲删查询参数。同图复用识别结果，再回填每个 SPU。空图、下载/解码失败单列，不算未检出。

## 执行器与输入

`scripts/watermark_scan.py` 是离线可配置识别器，不访问平台、不下载图片；取图由当前获准的浏览器/API 通道完成。Python 需要 OpenCV 和 NumPy；无依赖时先使用现场可用工具，不假定固定 Python 路径或系统。

```bash
python3 scripts/watermark_scan.py --manifest /run/products.json --profile /run/brand-profile.json --output /run/result --audit /run/audit.json
```

manifest 是数组，每行 `{ "spu": "精确字符串", "name": "商品名", "url": "原图地址", "path": "本地原图路径", "ocr": {"complete": true, "texts": ["OCR文字"]} }`。图片路径相对 manifest。没有主图时 url/path 为空。OCR 可由 macOS Vision 或现场已可用识别器生成；明确记录未执行/失败。外部识别服务涉及上传/付费时按当次授权执行，不能默认上传整店图片。

profile 示例（品牌和阈值均须替换并校准）：

```json
{
  "brands": [{"id":"brand-a", "terms":["目标品牌"], "templates":[{
    "path":"reference.png", "crop":[235,86,341,127], "mode":"highpass",
    "category":"文字水印", "scales":[0.5,0.7,0.85,1,1.15,1.3,1.6],
    "candidate":0.30, "hit":0.60, "calibrated":false
  }]}]
}
```

参考图与被检图片统一到 1000×1000，crop 坐标在该归一化空间；模板路径相对 profile。`mode` 为 `highpass` 或 `gray`。上述阈值仅用于启动试扫，不能继承为所有品牌的可靠标准。试扫同时复核命中、边界候选和部分未检出；用户确认后才将对应模板 `calibrated` 设为 true。不同风格和品牌分别校准。高通匹配拒绝近乎平坦区域，防止白底假高分。

audit 是以图片 SHA-256 为键的对象，值为 `{ "status":"命中或未检出", "brands":["brand-a"], "categories":["文字水印"], "reason":"视觉复核结论" }`。以内容绑定复核，避免商品换图后继承旧判断；相同图片全部关联 SPU 同步结果。品牌关键词即便识别正确，也仍需区分包装商标与目标水印。

执行器输出 `results.json`、`summary.json`、`matched-spu.txt` 和 `pending-spu.txt`，保留各品牌/模板得分与 OCR 证据。`未检出` 只表示当前规则未发现目标；OCR 未执行/失败且模板未命中时为 `识别未完成`，不能静默归阴性。空图和读取失败另外统计。输出目录应在任务目录而非 Skill 仓库。

## 规模化、复核与交付

沿用资源合同，检查内存和磁盘后以小并发下载/识别，保留失败重试与分批进度；不将本次机器绝对路径、商品数量或品牌阈值写死。已有原图可离线重复识别，模板/规则改变时重新计算，不能无条件使用旧缓存。

低置信度候选展示原图和匹配局部；人工排除背景文字、正常包装图案，补入弱水印。OCR 和图案证据并用，自动疑似不可混入确认命中。交付精确 SPU 总清单、按品牌/样式分类明细、可看原图的核对报告以及扫描范围/失败数。只要求 SPU 清单时不强制七表；要求标准运营工作簿时使用共享七表合同。

完成门：分页覆盖与 SPU 唯一性通过，所有图片都有结果或明确异常，同图判定一致，已确认试扫正例均保留或说明当前换图，总清单等于各类命中并集、文本 ID 无精度损失。候选未复核时明确剩余数量，不冒充全量确认。本流程零平台写入；焕新是独立任务。
